# Калькулятор стоимости комбайна + модификации НОМЕР 1

Это уже не простая Python-программа, которая помогает посчитать итоговую стоимость сельхозтехники, но еще и целый сайт (без вкусный, но я не веб дизайнер да и не хочется)
---

- Считает стоимость комбайна + выбранных модификаций
- Учитывает НДС (20%)
- Показывает рекомендации: если ты выбрал жатку — предложит бункер
- Сохраняет историю расчётов в `history.json`
- Сначала спрашивает данные пользователя (ФИО, компания и т.д.)
  
- Имеет REST API который я реализовал в test.py для наглядности ( не знаю как он поведет себя в гитхабе, но если перекачать весь проект себе на локальный компьютер и запустит то должно воркать, если нет , то минус бонуска )
но также можно попробывать через curl напрямую, но он выдаст ответ в JSON с Unicode-символами типо \u0416 и т.д т.п 

---
# Как использовать
Для начала нужно скачать release который я сделал и разархивировать его куда нибудь, после открыть в папке project консоль или shift+пкм powershell (на винде) и вписать py app.py , после перейти по сгенереному адрессу в браузер и  проверить работоспособность

для проверки же Rest api нужно включить еще одну консоль и запустить test.py или же просто в консоли ввести curl и адресс сайта
